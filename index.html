    About this prototypeA product concept for Hyper's task log, by Satya

    The concept

    While Hyper breezes through work, the onus of keeping track of it all falls on the user. Work disappears into chat history. There is no easy way to see what was done, what is still open, or what it was based on.

    The task log gives every piece of work a home. Each task shows which tasks have been done, what needs you, an auditable trail of everything that happened, artifacts produced and the sources it drew on, and you can act on it right there.

    What's simulated and what's real

    Simulated

    • The agent. Its replies are built from the sample data.
    • The people, replies, tools and sources.

    Designed to be real

    • The task list and how each status (Needs you, Waiting, Done) is worked out from what's still open.
    • The task page: what was done, needs attention, activity, artifacts and sources.
    • Draft, review, send, and watching the task update. Marking an item handled.
    • The task chat beside each task, and tracing any task back to the chat it came from.
